Snap — minimal screenshots from the menu bar

INSTALL
  Drag Snap into the Applications folder, then open it.

FIRST LAUNCH
  Snap isn't from the App Store, so macOS will block it the first time.
  1. Open Snap once and dismiss the warning.
  2. Go to System Settings → Privacy & Security, scroll down, and click
     "Open Anyway" next to Snap.
  3. Allow Screen Recording when asked (System Settings → Privacy &
     Security → Screen & System Audio Recording → turn on Snap), then
     quit and reopen Snap.

SHORTCUTS
  ⌥⌘S   Capture an area (drag) or a window (click)
  ⌥⌘F   Capture the full screen
  Esc   Cancel

Captures are copied to the clipboard and, optionally, saved to
~/Pictures/Screenshots. Change this from the menu bar icon.

Requires macOS 14 or later.
